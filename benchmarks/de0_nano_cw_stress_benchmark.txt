==============================================================================
WAU on real silicon - DE0-Nano example-program CW stress benchmark
==============================================================================

Reference runs captured 2026-07-06 on a Terasic DE0-Nano using the classic
2D WAU path and the repository's tracked `docs/example-program.cw` kernel.
This report records two things:

1. the largest example-program-class image that actually executed correctly on
   the board in this session, and
2. the larger grid attempts that were compiled and measured to establish the
   real hardware ceiling on EP4CE22.

Re-run with:

    cd demo/de0-nano/basic-example
    .\scripts\build_cw_stress.ps1 -GridX 2 -GridY 2 -QuartusRoot C:\intelFPGA_lite\23.1std
    .\scripts\program.ps1 -QuartusRoot C:\intelFPGA_lite\23.1std
    .\scripts\server.ps1 -QuartusRoot C:\intelFPGA_lite\23.1std
    .\scripts\run_cw_stress.ps1 -Config .\build\cw_stress_2x2_merged.json -RandomIters 1024 -RandomRange 1023 -Seed 1592594996

Note on toolchains:
  The local Quartus Standard 25.1 installation at
  C:\altera_standard\25.1std could not compile on 2026-07-06 because its
  evaluation had expired. All synthesis, programming, and live measurements in
  this report therefore used Quartus Lite 23.1 at
  C:\intelFPGA_lite\23.1std.

3. Architecture exploration on the real board target
------------------------------------------------------------------------------
All variants below were built from the same `docs/example-program.cw` source
and the same board wrapper. Only the WAU grid size changed.

  grid   compile status   area / timing summary                      live status
  -----  ---------------  ----------------------------------------   -------------------------
  4x4    failed fit       61 564 / 22 320 LE (276 %), 96 / 132 DSP  no bitstream
  2x5    failed fit       39 747 / 22 320 LE (178 %), 60 / 132 DSP  no bitstream
  2x4    fit succeeded    22 166 / 22 320 LE (99 %), 48 / 132 DSP   0 / 8 golden pass
  2x2    fit succeeded    10 372 / 22 320 LE (46 %), 24 / 132 DSP   1032 / 1032 pass

2x4 timing summary:
  Slow 1200 mV 0 C setup slack   : -167.709 ns
  Fast 1200 mV 0 C setup slack   : -101.518 ns

2x2 timing summary:
  Slow 1200 mV 85 C setup slack  : -32.413 ns
  Slow 1200 mV 0 C setup slack   : -27.203 ns
  Fast 1200 mV 0 C setup slack   : -10.195 ns

Honest reading:
  The board can be programmed with a much larger 2x4 image, but that image is
  not usable at 50 MHz for this workload: every golden case timed out, and the
  observability counters were already corrupted by timing failure. In this
  session, 2x2 is the largest `example-program.cw` image that both fit and
  executed correctly end-to-end on the DE0-Nano.

8. Repaired program-profiled 2x4 image (2026-07-13)
------------------------------------------------------------------------------
The 2026-07-06 timeout is retained above as failure telemetry, but it is no
longer the board ceiling. A new `fit-config` profiled candidate inferred each
core's exact scheduled operation set, and the emitter made those rows structural
ALU constraints. The board wrapper runs WAU/JTAG from CLOCK_50 / 16 (3.125 MHz)
while elastic router cuts are pending.

Tools used for build  : Quartus Prime Lite 25.1std.0 Build 1129
Candidate             : g2x4x1_profiled_balanced_mif1
Grid                  : 2 x 4 (8 cores)

Multiplier elements   : 12 / 132 (9-bit)

  throughput          : 95.4 ops/s
  p50 / p95           : 15.00 / 16.00 ms
  hops / stalls       : 82 560 / 0
  forwards / delivered: 47 472 / 35 088
  cache hits / lookups: 8 / 17 544

Machine-readable report:
  benchmarks/de0_nano_cw_stress_2x4_profiled_20260713.json

The live harness now aborts on the first watchdog expiry, records
`execution_status=circuit_hang`, and returns exit code 3. It never continues a
broken circuit to produce timeout-limited throughput.

Separate ad-hoc prediction for `CWs/stress/mesh_stress.cw` recommends
`g2x3x1_profiled_balanced_mif1` (6 cores, 43-cycle makespan). Generated RTL
completed 8/8 simulator cases in 867 cycles. Its Quartus 25.1 fit was stopped
after an unusually long active placement search; no silicon result is claimed.

The DE0-Nano has 32 MB external ISSI SDRAM, not SRAM. It is currently inactive
and not counted as cache. Active station caches are register-based (1..32
entries per core); an SDRAM controller/cache remains future work.
