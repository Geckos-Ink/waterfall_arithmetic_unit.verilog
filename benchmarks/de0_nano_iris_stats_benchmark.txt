WAU on real silicon - DE0-Nano Iris morphology benchmark
==============================================================================

Reference runs captured 2026-07-06 on a Terasic DE0-Nano using the classic
2D WAU (2x2 grid). This is the first tracked real-data statistical workload
for the board demo: 150 Iris samples streamed over vJTAG into a 10-stage
fixed-point flow, with every board result checked against a host-side
reference that mirrors the staged WAU program exactly.

Re-run with:

    cd demo/de0-nano/basic-example
    .\scripts\build.ps1 -QuartusRoot C:\intelFPGA_lite\23.1std
    .\scripts\program.ps1 -QuartusRoot C:\intelFPGA_lite\23.1std
    .\scripts\server.ps1 -QuartusRoot C:\intelFPGA_lite\23.1std
    .\scripts\run_iris_stats.ps1

Note on toolchains:
  The demo scripts default to Quartus Standard 25.1 at
  C:\altera_standard\25.1std, but on 2026-07-06 that installation on this
  machine could not compile because its 30-day evaluation had expired.
  Synthesis/programming for this report therefore used Quartus Lite 23.1 at
  C:\intelFPGA_lite\23.1std. The FPGA was programmed successfully over the
  same USB-Blaster path used by the rest of the demo flow.

------------------------------------------------------------------------------

Operation set         : add, sub, mul, max
Multiplier mapping    : mul stages pinned to core (1,0)
Station cache         : 2 entries, FIFO replacement

Hardware formula (scaled integer domain, a=sepal_length_tenths,
b=petal_length_tenths):

    acc = a

    acc = acc * 4
    acc = acc + b
    acc = acc - 44
    acc = acc * 3
    acc = acc + 32
    acc = max(acc, 0)
    acc = acc * 2
    acc = acc - 80
    acc = max(acc, 0)

This uses the board's existing 2D WAU fabric only; no 3D layering is involved
in the DE0-Nano validation path.

Interpretation:
  The fixed-point flow is not a classifier. It is a compact morphology score

  median and tail.
